## 📌 Key Files to Customize

1. **inventory.ini** - Device hostnames and IP addresses
2. **group_vars/all.yml** - Global settings (NTP, DNS, AAA servers)
3. **group_vars/ios_devices.yml** - IOS device defaults
4. **group_vars/fmc_devices.yml** - Firepower defaults
5. **group_vars/all/vault.yml** - Encrypted credentials (CREATE THIS)
6. **host_vars/core-switch-01.yml** - Your switch configuration
7. **host_vars/ftd-sensor-01.yml** - Your FTD configuration

## 🔒 Security Files (NEVER COMMIT)

- `group_vars/all/vault.yml` - Keep encrypted and secure
- `.vault_pass` - Store locally, never commit
- SSH private keys - Use key-based authentication

## 📂 Working Directories

- `logs/` - Playbook execution logs and reports
- `backups/` - Device configuration backups
- `facts/` - Device facts in JSON format
- `reports/` - Generated HTML reports
